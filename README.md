# 神都周末 🏮 洛阳文旅 AI 向导（从河科大出发）

> 面向河南科技大学学生的周末出行决策工具——输入「时间 × 预算 × 兴趣」，本地规则引擎生成含**学生半价门票、地铁接驳、末班车预警**的行程敕牒。

**🚀 在线体验**：` https://gwswucan.github.io/shendu-weekend/`
**📦 源码直链**（华为云 OBS，点开即下载）：`https://shendu-weekend-haust.obs.cn-north-4.myhuaweicloud.com/index.html`

---

## ✨ 核心功能

| 模块 | 说明 |
|------|------|
| 🀄 AI 行程敕牒 | 聊天式输入（如「周六一天 60 元 想看历史」）→ 逐时段行程卡：时间轴 + 学生票价 + 地铁链路 + 费用账目 + 「准予出行」印章 |
| 🗺️ 路线模板 | 6 套现成行程（半日/一日/两日 × 历史/美食/夜游），一键载入 |
| 📇 景点图鉴 | 24 处（龙门石窟、白马寺、九洲池、神都十三坊…）：学生价/凭证要求/从开元校区出发的完整地铁路线 |
| 🧮 预算计算器 | 勾选景点+餐饮档位 → 账房票据式估算，与行程数据同源 |
| 🍜 觅食图鉴 | 13 家老字号（真不同水席、小街锅贴、马杰山牛肉汤…）人均区间+导航链接 |
| 📋 出行贴士 | 学生证优惠清单 / 地铁速查 / 时间红线 / 汉服租赁避坑 / 夜游演出时刻表 |
| 🖼 敕牒海报 | Canvas 生成国潮票据海报，下载/复制文案，晒图进群 |

## 🛠 技术特点

- **单文件 HTML**（~100KB）：零框架、零后端、零外部运行时依赖，断网可演示（NFR-5）
- **本地智能规则引擎**：意图解析（时长/预算/兴趣三槽位 + 景点直提）+ 四条硬约束（时长上限 / 冬令时 17:00 止票提醒 / 返程 ≤22:00 / 预算自动降档）
- **单一数据源架构**：24 景点 × 13 餐馆 × 地铁票价全部收敛于一个 `DATA` 对象，页面渲染与引擎计算永不出现两处价格
- **神都粗野国潮视觉**：宣纸底 + 墨色粗描边 + 硬投影 + 牡丹红/唐黄/琉璃青 + 敕牒/印章隐喻

## 📐 规格驱动开发（SDD）四件套

本作品按「规格 → 设计 → 任务 → 实现」流程开发，完整文档随仓库提交：

| 阶段 | 产出物 |
|------|--------|
| 1. 规格 | `规格书.md` — 10 条可测验收标准（AC） |
| 2. 设计 | `设计方案.md` — 视觉系统/信息架构/交互流程/数据结构 |
| 3. 任务 | 实施计划（P0→P1→P2 优先级砍单） |
| 4. 实现 | `index.html` + `验收记录.md`（**AC 10/10 通过**，验收中修复 3 缺陷） |

## 🚇 数据口径

地铁线路/运营时间：洛阳轨道交通官网；龙门石窟票价与冬令时检票时间：景区官方公示；
餐馆人均：携程美食 2026-10 数据。全部核实于 2026-10，页脚标注口径声明。

## 🎯 适用对象

河科大学生（开元校区为行程原点）· 洛阳其他高校学生参考可用 · 活动评审演示
